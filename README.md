# GPT2Code Project

This project demonstrates a Python application with advanced CSV import capabilities.

## Features
- CSV data import with automatic delimiter detection (comma/semicolon)
- Quote character detection (single/double quotes)
- Robust validation and error handling
- Greeting message generation
- Comprehensive unit testing

## Requirements
- Python 3.9+

## Installation
```bash
pip install -e .
```

## Running Tests
```bash
python -m unittest discover tests
```
